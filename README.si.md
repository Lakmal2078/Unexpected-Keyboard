Android සඳහා නිර්මාණය කළ, සැහැල්ලු සහ පෞද්ගලිකත්වයට මුල්තැන දෙන අතථ්‍ය යතුරුපුවරුවකි.

https://github.com/Julow/Unexpected-Keyboard/assets/2310568/28f8f6fe-ac13-46f3-8c5e-d62443e16d0d

යතුරු ඒවායේ කොන් දෙසට ස්වයිප් කිරීමෙන් තවත් අක්ෂර ටයිප් කළ හැකි වීම මෙහි ප්‍රධාන විශේෂාංගයයි.

මෙම යෙදුම මුලින් නිර්මාණය කළේ Termux භාවිතා කරන ක්‍රමලේඛකයන් සඳහාය. දැන් එය එදිනෙදා භාවිතයටත් සුදුසුය.

මෙම යෙදුමේ දැන්වීම් නැති අතර එය විවෘත මූලාශ්‍රයකි.

**භාවිතය:** යතුරුවල කොන්වල පෙන්වන සංකේත ඇතුළත් කිරීමට, එම සංකේතය ඇති දිශාවට ඇඟිල්ල ස්වයිප් කරන්න. උදාහරණයක් ලෙස, වම්-පහළ කෙළවරට ස්වයිප් කිරීමෙන් Settings විවෘත කළ හැක.
